# AI-Powered Personal Shopper for Online Shopping Platforms

## Project Description
This project aims to develop an AI-powered personal shopping assistant that helps online shoppers compare products across supported e-commerce platforms, such as Shopee and Lazada. The system will analyse customer reviews using Natural Language Processing (NLP) and rank products based on user preferences to help shoppers make more informed purchasing decisions.

## Problem Statement
Online shoppers often need to switch between multiple e-commerce platforms to compare product prices, features, and customer reviews. This process can be time-consuming and makes it difficult to identify products that provide the best value.

## Objectives
1. Develop a web application for comparing products from supported e-commerce platforms.
2. Implement NLP-based review sentiment analysis and preference-based product ranking.
3. Evaluate the system based on sentiment-analysis performance, recommendation relevance, and response time.

## Target Users
Online shoppers who want to compare products, understand customer feedback, and find products that match their preferences and budget.
